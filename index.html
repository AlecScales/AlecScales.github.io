Projects

RowELO: Elo Rankings for British Junior Rowing

An automated pipeline that scrapes regatta results, cleans and stores them in a MySQL database, calculates Elo ratings for clubs, and publishes the results as a static website with league tables and interactive charts.

  • Combines results from three regattas into one platform: 228 races across 18 events and 74 clubs over five seasons.
  • Built with Python, MySQL, asynchronous scrapers, HTML, CSS and JavaScript.

Live demo GitHub repo
